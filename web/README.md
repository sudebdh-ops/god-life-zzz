# god life zzz — PC 크롬 버전

별도의 npm 패키지 설치 없이 실행하는 오픈소스 루틴 앱입니다. 같은 화면을 일반 웹 앱과 크롬 확장 프로그램에서 사용합니다.
모든 스크립트와 아이콘은 프로젝트에 포함돼 있습니다. 친구·기기 동기화는 Supabase 무료 프로젝트와 인터넷을 사용하며, 연결하지 않으면 로컬로만 작동합니다.

## 권장: 크롬 확장 프로그램으로 사용

이 방식은 앱 탭을 닫아도 **크롬이 실행 중이면** 루틴 알림을 받을 수 있습니다. 크롬 웹 스토어 등록은 필요 없습니다.

1. 소스 ZIP을 압축 해제합니다.
2. 크롬에서 `chrome://extensions`를 엽니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 `web` 폴더를 선택합니다.
5. 확장 프로그램 아이콘 목록에서 **god life zzz**를 고정합니다.
6. 아이콘을 클릭하면 앱이 새 탭으로 열립니다.
7. 설정의 **테스트 알림**을 누르고 Windows 알림을 확인합니다.

확장 프로그램의 권한은 `storage`, `alarms`, `notifications`와 이 앱의 Supabase 프로젝트 접속뿐입니다. 모든 웹사이트 접근이나 브라우징 기록 읽기 권한은 없습니다.
1분 간격의 Chrome 시스템 알람으로 저장된 예약을 확인합니다. 분 단위 정확도를 보장하지 않으며 OS·Chrome 상태에 따라 늦어질 수 있습니다.
컴퓨터가 꺼져 있거나 크롬을 완전히 종료하면 알림은 실행되지 않습니다. 절전 중 놓친 당일 알림은 복귀 후 늦게 도착할 수 있고, 지난 날짜의 알림은 보내지 않습니다.
기기 시간대가 바뀌면 앱/확장 프로그램을 다시 열어 예약을 확인하세요.

확장 프로그램 업데이트는 같은 폴더에 새 파일을 넣은 뒤 확장 프로그램 관리 화면에서 **새로고침**을 누르세요.
확장 프로그램을 삭제하거나 다른 크롬 프로필을 사용하면 기록이 유지되지 않을 수 있습니다. 먼저 백업하세요.

## 일반 웹 앱으로 실행

Node.js LTS가 설치된 컴퓨터에서:

```sh
node server.mjs
```

또는 `start-web.cmd`를 실행하고 크롬에서 **http://127.0.0.1:4173**을 엽니다.
개발 서버는 현재 컴퓨터의 loopback 주소에만 열립니다. 첫 로딩 후 오프라인 캐시를 사용합니다.

로컬 서버가 실행 중일 때 위 주소로 앱을 열 수 있습니다.
일반 웹 버전의 리마인더는 **페이지가 열려 있는 동안** 동작합니다. 탭을 닫으면 예약 알림이 실행되지 않습니다.
크롬 메뉴에서 페이지를 앱으로 설치해도 이 제한은 같습니다. 백그라운드 알림이 목적이면 확장 버전을 사용하세요.

## 친구·기기 동기화

설정에서 한 사람이 공유 공간을 만들고 초대 코드를 친구에게 보냅니다. 친구는 자신의 이름과 그 코드를 넣어 참여합니다. 각자의 복구 코드는 새 기기 연결용이니 따로 안전하게 보관하세요. 루틴 설정은 공유되고 완료는 각자 체크합니다. 기존 로컬 루틴은 ‘내 루틴’의 **친구와 공유**를 눌러야 올라갑니다. 연결 후 새로 만드는 루틴은 자동 공유됩니다.

확장 프로그램은 Chrome 실행 중 약 1분마다, 일반 웹 페이지는 열려 있는 동안 약 1분마다 동기화합니다. 오프라인에서 공유 루틴을 수정하거나 완료 체크하면 서버에 반영되지 않으므로 연결이 돌아온 뒤 다시 시도해야 합니다. 개인 루틴은 계속 로컬로 쓸 수 있습니다.

## 백업과 기록 옮기기

안드로이드와 웹/확장 버전은 같은 `version: 1` JSON 백업 형식을 사용합니다.
설정에서 백업 파일을 저장한 뒤 다른 기기에서 가져오면 됩니다.
같은 ID의 루틴은 현재 설정을 유지하면서 완료 기록만 합칩니다. 새 루틴은 추가하며 기존 기록은 삭제하지 않습니다.
백업 파일은 이 기기의 루틴과 내 완료 이력을 담습니다. 공유 루틴을 가져온 뒤 동기화하면 서버의 설정·완료 기록이 우선합니다. 일반 웹 버전과 확장 버전은 별도 저장 공간이지만 같은 복구 코드로 연결할 수 있습니다.

## 테스트 및 구조

```sh
node --test tests/*.test.mjs
```

- `core.js`: 안드로이드와 동일한 루틴/백업 규칙, 예약 및 연속 달성 계산
- `app.js`: 화면과 편집 흐름, 백업, 저장소 연결
- `background.js`: 크롬 확장 프로그램의 알람·알림·직렬화된 데이터 변경
- `sync-client.js`, `sync-engine.js`: 서버 통신과 공유 루틴 조정
- `manifest.json`: 크롬 확장 프로그램 설정
- `app.webmanifest`, `sw.js`: 설치형 웹 앱과 오프라인 캐시
- `server.mjs`: 로컬 정적 파일 서버
- `tests/`: 루틴 로직과 모의 Chrome API 통합 테스트
